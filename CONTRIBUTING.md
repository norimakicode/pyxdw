# Contributing

Issues and pull requests are welcome.

- Never attach real business documents. If a file is needed to reproduce a problem,
  create one with the official DocuWorks API or Desk containing only dummy content,
  and describe how it was made.
- New write features need evidence that the output matches the official API
  (byte comparison or the steps used) and opens in DocuWorks Viewer.
- Keep the library dependency-free and pure Python.
- Run `python -m unittest discover -s tests`.
